# ฟอนต์ที่มากับโปรเจกต์

Sarabun (Regular, Bold) — ฟอนต์ไทย/ละติน ใบอนุญาต SIL Open Font License 1.1 (ดู `OFL.txt`)
ที่มา: https://github.com/google/fonts/tree/main/ofl/sarabun

ใช้กับ `scripts/make_synthetic_samples.py` (วาดชุดภาพสังเคราะห์) และ `scripts/visualize_oxr.py` (ป้ายบนภาพ)
เก็บไว้ในโปรเจกต์เพื่อไม่ต้องพึ่งฟอนต์ของเครื่อง (เช่น Tahoma/Arial ของ Windows ซึ่งนำมาแจกจ่ายไม่ได้)
