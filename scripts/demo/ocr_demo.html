OCR ทีละขั้น

อัปโหลดเอกสาร 1 ไฟล์ แล้วดูว่าแต่ละขั้นของ fin_extractor ทำอะไรกับมัน ตั้งแต่ภาพดิบจนได้ JSON สุดท้าย · คลิกกรอบ/รหัสส่วน (เช่น s03) ที่ไหนก็ได้เพื่อตามส่วนนั้นข้ามทุกขั้น

เริ่ม: เลือกเอกสาร

ลากไฟล์มาวาง หรือคลิกเพื่อเลือก · jpg / png / tif / pdf (PDF ใช้หน้าแรก)

ปรับภาพและแบ่งส่วนด้วยค่าตั้งต้นของ flow หลัก (sections) ให้อัตโนมัติ: ตรวจทิศหน้าเอง · แก้เอียง · คงสี · ระบาย QR/บาร์โค้ด · แบ่งเป็น region ชิดข้อความ (--layout regions)

LLM (hybrid / winner) เรียก Ollama ในเครื่อง ต้องเปิด Ollama และมีโมเดลตาม llm_extractor.model ถ้าเรียกไม่ได้จะถอยไปใช้ rules และแจ้งในขั้นสกัด · วัดบน 18 ใบ: hybrid ไม่เพิ่มค่าที่ไม่อยู่ในข้อความ winner แต่งค่าได้ (docs/05-extraction.md §5D)
ขั้น OCR ใช้ GPU (openthai โหลดโมเดลในเครื่อง · typhoon ต้องเปิด Ollama · paddle) รันได้ทีละงาน และอ่านทีละส่วนเหมือน flow จริง ไฟล์ 1 หน้ามักมี 10–25 ส่วน
